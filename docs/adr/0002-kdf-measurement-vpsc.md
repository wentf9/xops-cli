# ADR-0002：vpsc 低配服务器 KDF 初测

- 日期：2026-09-10
- 关联：[ADR-0002](0002-offline-encrypted-credential-store.md)
- 性质：受限资源下的小样本可行性测量，不是完整后端或安全验收

## 环境与保护措施

用户授权在 vpsc（1c1g）测量，要求不影响服务器运行。实测为 Ubuntu 24.04.4 LTS、
Linux amd64、一个逻辑 CPU，CPU 型号为 Intel Xeon E5-2690 v4 2.60 GHz；
MemTotal 为 959988 KiB，无 swap。开始时 MemAvailable 为 460612 KiB，
一分钟负载为 0.28，memory PSI 的 some/full avg10 均为零。

探针在本地以 Go 1.26.7、golang.org/x/crypto v0.55.0、CGO_ENABLED=0 编译，
远端仅上传到独立 0700 临时目录，不安装软件、不修改服务或持久配置。
使用用户级临时 systemd unit，逐次运行并自动回收：

```text
CPUQuota=10%
CPUQuotaPeriodSec=100ms
MemoryMax=128M
MemorySwapMax=0
Nice=19
RuntimeMaxSec=20s
LimitCPU=2
LimitCORE=0
TasksMax=16
GOMAXPROCS=1
GOMEMLIMIT=96MiB
```

运行前用无计算负载的临时 unit 验证 cgroup 实际值：cpu.max 为 `10000 100000`，
memory.max 为 `134217728`。首次 t=3 通过后，追加八次串行采样，追加采样间隔
两秒；每次追加前检查 MemAvailable 至少 384 MiB、memory PSI some avg10 为零，
不满足则停止。没有测试更高内存参数，也没有独占 CPU 或持续压测。

CPU 限额、内存限额仅作用于测试 unit；GOMEMLIMIT 是 Go 软目标，硬限制来自
MemoryMax。限额不能证明业务零影响，本次没有业务延迟或服务 SLO 观测。

## 方法与原始结果

每个新进程只执行一次 `argon2.IDKey`，内存参数 65536 KiB、并行度 1、输出
32 字节；使用固定公开测试口令 `public-test-password-only` 和 17 字节测试 salt
`public-test-salt!`，不读取真实凭据，也不输出派生密钥。
原记录误写为 16 字节，阶段 A 独立向量核对时修正；本次性能探针未遵循后来
固定的格式 v1 的 16 字节 salt，不能作为该格式的完整验证。
墙钟时间仅围绕 IDKey；CPU 时间和峰值 RSS 来自进程 Getrusage，包含进程开销。

首次 t=3 的较慢原因未确认，不归因于某个未经验证的系统因素。

## 观察与参数建议

- 峰值 RSS 为 66.25 MiB，九次均在 128 MiB 的测试硬限额内正常退出。这只说明
  当前探针的资源使用，不是未来完整 helper 的 RSS 上限。
- 保留 ADR 建议的 64 MiB、t=3、p=1 为默认候选：本机受限测试均完成，不需要
  为本次低配环境直接降低为 t=2；不以少量时间数据决定密码学最低安全参数。
- t=3 最慢样本约 7.63 秒，单次 KDF 与当前 30 秒 unlock_timeout 候选相容。
  未测队列等待、完整内部协议或多库争用，不能保证排队后仍在 30 秒内完成。
- 128 MiB 是本次隔离上限，不是已验收的产品内存上限；完整 helper 开销、取消
  与进程回收仍需独立验证。

后续决策：用户已采纳首版固定 64 MiB、t=3、p=1、输出 32 字节，读写仅接受
该组合，资源不足失败关闭；128 MiB 作为完整 helper 待验收预算。以上原始测量
和当时的候选建议保留，正式约束以 ADR-0002 的“KDF 参数与内存策略”为准；
决策采纳不增加本次测量的证明范围，也不代表密码学审查或完整 helper 验收通过。

测试前后 memory PSI 累计值保持 some=217294520、full=197474879 微秒，
没有观察到新增内存压力。结束采样存在短时 I/O wait，未对来源进行归因。
清理后 MemAvailable 为 488424 KiB、一分钟负载为 0.12；这些主机指标不能替代
业务可用性验证，结论限定为未观察到新增内存压力且探针正常退出。

远端探针和临时目录已删除，确认无 probe 进程残留；临时 unit 使用 --collect 回收。
