# 命令参考

[完整命令列表](./commands/)由当前源码构建的 CLI 帮助自动生成，覆盖中英文命令说明、选项及子命令。

| 任务 | 命令 |
| --- | --- |
| 初始化 | [init](./commands/xops-init) |
| 管理资产 | [host](./commands/xops-host)、[identity](./commands/xops-identity) |
| 远程连接 | [ssh](./commands/xops-ssh)、[sftp](./commands/xops-sftp) |
| 执行与传输 | [exec](./commands/xops-exec)、[scp](./commands/xops-scp) |
| 凭据诊断 | [credential](./commands/xops-credential) |
| 自动化 | [play](./commands/xops-play)、[mcp](./commands/xops-mcp) |

这些页面描述当前源码，不是多版本快照。针对已安装程序，请使用 `xops <command> --help`。
