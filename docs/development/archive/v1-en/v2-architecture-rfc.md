## 0. Locked Architectural Decisions (ADR 001–016, v2.2 Calibrated Final)

| ID | Decision Domain | Finalized Choice |
| :--- | :--- | :--- |
| **ADR-001** | **Go 1.27+, `encoding/json/v2` & Multi-Module Isolation** | Standardize on **Go 1.27+** and `encoding/json/v2` (ban bare `time.Duration` in DTOs via `algebraic.Duration` implementing `TextAppender`/`TextMarshaler`; implement `TextAppender`/`TextMarshaler` on all serializable opaque value objects; deliberately omit marshalers on `SecretBox` for native `SemanticError` fail-closed; enable `Deterministic(true)` for hashing/golden tests). Enforce physical boundaries via 3-module workspace (`core/go.mod`, CLI root `go.mod`, `tools/xopsvet/go.mod`). |
| **ADR-002** | **Multi-Module Responsibility Split** | Complete host-agnostic hexagonal core lives in `core/`; CLI host owns only local YAML/WAL storage, local Vault/Keychain/Helper, `~/.ssh/config` parser, thin driving adapters, and the composition root. |
| **ADR-003** | **`core/` Public Contract Surface** | Export ONLY 5 packages: `core/domain/...`, `core/ports` (+ `tck`), `core/events`, `core/osfs`, `core/engine`. Everything else (including `Authorized[C]`, `pool`, `gate`, `usecase/*`, `mcpruntime`, `sshnet/*`, `sim`) is sealed inside `core/internal/`. |
| **ADR-004** | **OpenSSH Integration Boundary** | Full core OpenSSH experience (`~/.ssh/config` live virtual nodes, 4-tier option monoids, `ProxyJump`/`ProxyCommand`, `ControlMaster`/`ControlPersist`) unified through one pure algebraic solver and `NodeOrigin` sum type. |
| **ADR-005** | **Business Feature Parity** | Retain all existing capabilities (SSH/Mux/forwards incl. TUN, SCP/SFTP shell, batch `exec`, Playbook, TUI incl. monitor/logs, MCP stdio/HTTP/10GiB transfer/tunnel/GUI, Vault/Keychain/Helper), cleanly rewritten. |
| **ADR-006** | **Zero-Compat Contracts & `FormatImporter` Hook** | Redesign YAML vNext (`version: 2`), Vault vNext, discriminated Playbook & MCP schemas, and clean CLI flags (retaining OpenSSH short-flag muscle memory). Keep **100% zero v1 migration code**, while reserving a unified `FormatImporter` / `ImportBundle` extension point (`openssh`/`csv` built-in). |
| **ADR-007** | **Persistence, Dual-Mode Local FS Ports & Windows Sidecar Locks** | Zero-CGO pure Go: YAML vNext + structured WAL/JSONL. Split local FS into two physically separate ports: **`ScopedRootFS`** (Go `*os.Root` sandbox for all writes, `~/.xops`, SCP downloads, and ALL MCP/Agent paths) and **`OperatorReadFS`** (`WithOperatorRead` for CLI/Playbook arbitrary read-only human inputs across Windows drives/symlinks — **physically never injected into `mcpruntime`**). `core/osfs` always locks a sidecar `<name>.lock` inside the same `os.Root`, never locking the data file before `Root.Rename`. |
| **ADR-008** | **Sealed `gate.Authorized[C]`, O(1) Crash Reconciliation & `Halted` Breaker** | Define **`Authorized[C]` inside `core/internal/gate`** (100% compiler-sealed; `core/domain/security` stays pure math) and mint via package-level generic **`gate.WithAuthorized[C](ctx, g, req, run)`**. Hold a process-lifetime kernel lock `~/.xops/run/<ProcessInstanceID>.lock` recording active unclosed `OperationID`s: clean startup is **O(1) zero-scan** of `audit.jsonl`; dead locks are claimed via exclusive non-blocking `TryLock`, reconciled with `AbortedByCrash` under a short cross-process append lock, and atomically unlinked. Under `StrictAgentProfile`, `AuditPostWriteError` trips `Halted` and invokes outbound `OnHaltFunc` to revoke all pool `ManagedHandle`s and deny new calls. |
| **ADR-009** | **Decoupled Pool & 6 Dual-Channel Actor Concurrency Laws** | **`core/internal/pool` never imports `core/internal/sshnet`** (depends strictly on `core/ports`, wired by `core/engine`). Dual-mode ownership (`WithLease`/`WithMultiLease` + Generational SlotMap) obeys 6 laws: (1) dual channels (bounded `acquireCh` + never-blocked `controlCh`); (2) **two-stage `select`** draining `controlCh` non-blockingly before blocking on both; (3) 100% pure in-memory non-blocking Actor loop; (4) strict Control-Plane vs Data-Plane separation; (5) **strict nesting order `gate.WithAuthorized` wraps `pool.WithLease`** + `actorDone` select on `ReleaseLease`; (6) `trace.LeaseScope` injected **only upon entering user callback `fn(scopedCtx, sess)`** (not during internal multi-hop DAG dialing), with topological `WithMultiLease`. |
| **ADR-010** | **Scoped Dual-Layer Event Streams** | Isolated per-call `OperationStream` (deterministic EOF, `BlockWithContext` vs `CoalesceLatest`, pure `Fold`) + sync fail-closed `AuditSink` + bounded non-blocking `SystemBus` (`DropAndCount`). |
| **ADR-011** | **100% Scoped Closures & Precision `xopsvet` Zero-Bypass** | Package-level capability whitelisting with **0 inline `//nolint`** outside whitelisted packages. Eliminate the last imperative `mustclose` handle by turning `SecretVault`/`CredentialService` into **`WithSecret(ctx, ref, func(box *SecretBox) error)`** (`defer box.Wipe()` by provider, `SecretBox` marked `//xops:borrowed`). `xopsvet` runs 5 AST/Types analyzers + precise local `linearlease` + type/local direct-sink `secrettaint` + scoped `failclosed` (exempting pure `errors.Is`/`AsType` classifiers). |
| **ADR-012** | **Walking Skeleton Vertical Slice (`Phase 2.5`)** | Right after `Gate G2`, ship and test a minimal pure-v2 `xops ssh` vertical slice across native Linux/Windows(ConPTY)/macOS (`Gate G2.5`) before parallel Phases 3 & 4 fan-out. |
| **ADR-013** | **Calibrated Complexity & File-Size Ceilings** | Cognitive complexity **`gocognit <= 15`** (zero clash with flat `sumexhaust` `type switch`es); package <= 3,000 LOC; file <= 500 LOC (<= 800 LOC for suffixed `*_spec.go`/`*_variants.go`/`*_codec.go`). |
| **ADR-014** | **Idiomatic Go & Zero-`sync` Domain Purity** | Idiomatic `(T, error)` (no `Result[T]`); `Option[T]` strictly for unset-vs-zero struct fields; single-goroutine `SecretBox` (`wiped bool`) + `Authorized[C]` in `gate` keeps **`core/domain/**` 100% free of `sync` and `sync/atomic`**. |
| **ADR-015** | **`ssh.Channel` Cancel/Deadline Watchdog** | Every multi-hop `ssh.Channel` virtual `net.Conn` in `sshnet/dial` wraps a `Nursery`-supervised Cancel/Deadline Watchdog closing the channel on timeout/cancel to unblock `Read`. |
| **ADR-016** | **Honest Threat Models (`SecretBox` & SFTP v3)** | `SecretBox` targets leak prevention (logs/audit/errors/events/YAML/plans/digests) + owned-buffer `clear()` without forking `x/crypto/ssh` (optional `goexperiment.runtimesecret` hook). SFTP v3 two-phase canonicalization targets Confused Deputy / static symlinks, complemented in `sshnet/sftp` by non-truncating open + `SSH_FXP_FSTAT` type/`(dev,ino)` verification and atomic `posix-rename@openssh.com`. |

## 2. Core Precision Contracts, Use Cases & Engineering Defense Summary

- **Compiler-Sealed `gate.Authorized[C]`**: Defined in `core/internal/gate` with private fields + atomic `revoked` flag, minted solely via package-level `gate.WithAuthorized[C](ctx, authorizer, req, run)`. `core/domain/security` holds pure mathematical types (`Capability`, `Verdict`/`RiskLevel`/`Decision` lattices, `Policy`, `ApprovalEnvelope`), keeping `core/domain/**` 100% free of `sync` and `sync/atomic`.
- **Zero Imperative `mustclose` Handles**: `Pool.WithLease`/`WithMultiLease`, `SecretVault.WithSecret` + `SecretBox.Use`, `ScopedRootFS.WithRoot` (Go `*os.Root` + sidecar `<name>.lock`), `OperatorReadFS.WithOperatorRead` (never injected into `mcpruntime`), and `gate.WithAuthorized` enforce scoped lexical ownership everywhere + runtime revoked-borrow sentinels.
- **Sealed Sum Types, Monoids, Lattices & 5 Pure Mealy FSMs**:
  - Sealed Sum Types checked by `sumexhaust`: `AuthMethod`, `ChallengeRule`, `NodeOrigin`, `ProxyRoute`, `ExecutionOutcome` (only `OutcomeNotStarted` retryable), `ExitStatus`, `GuardrailDecision`, `StepAction`, `TransferState`, `VaultSagaState`, `Event`. Idiomatic Go `(T, error)` everywhere (no generic `Result[T]`).
  - OpenSSH 4-tier monoid `(OptionLayer, ⊕, Unset)` folded through single pure `option.ResolveEffectivePolicy`; security lattices (`Verdict` meet, `RiskLevel`/`Decision` join) fold order-independently.
  - 5 pure Mealy FSMs (`Transition(S, I) -> (S', []Effect, []Event)`): `VaultSagaFSM`, `ApprovalFSM`, `TransferFSM`, `EnsureFSM`, `PendingEnrollFSM`.
- **Two-Stage `DualActor` & O(1) Crash Reconciliation**: Non-blocking `controlCh` drain before blocking dual `select` (backed by an unbounded ring queue + 1-buffered wakeup signal); `gate.WithAuthorized` always wraps `pool.WithLease`; `ReleaseLease` selects on `actorDone`; `trace.LeaseScope` injected strictly upon user-callback entry; `ssh.Channel` multi-hop conns wrapped in `Nursery` Cancel/Deadline Watchdog; `~/.xops/run/<ProcessInstanceID>.lock` uses an **append-only `+<opID>`/`-<opID>` protocol** (truncating only when active count reaches 0, and on Windows truncating before unlock/close/remove) enabling O(1) zero-scan clean startup and single-winner verified `AbortedByCrash` recovery. All 3 `go.mod` files stay strictly `replace`-free (`core/` & `tools/xopsvet/` always run `GOWORK=off`; root CLI runs via `go.work` during branch dev and `GOWORK=off` once `core/v2.0.0` is tagged).
- **Six Unified Use-Case Services & Zero-Compat Contracts**: `InventoryService` (incl. pluggable `FormatImporter` / `ImportBundle` with `openssh`/`csv` and 0 v1 code), `CredentialService` (`WithSecret`), `SessionService`, `TransferService` (`sshnet/sftp` non-truncating open + `SSH_FXP_FSTAT` type/`(dev,ino)` anchor + atomic `posix-rename@openssh.com`), `AutomationService`, and `ObservabilityService`. YAML vNext (`version: 2`), Vault vNext (Argon2id + XChaCha20-Poly1305 AEAD), discriminated Playbook & 7 MCP tools (`nodes`, `terminal_exec`, `terminal_session`, `file`, `transfer`, `tunnel`, `gui`), Go 1.27 `encoding/json/v2` (`algebraic.Duration` + `TextAppender` on opaque values + `Deterministic(true)` + fail-closed `SecretBox`).
- **8 Precision `tools/xopsvet` Analyzers (0 inline `//nolint` outside whitelists)**: `archbound`, `sumexhaust`, `linearlease` (no bare `go` outside `conc` + local borrowed closure non-escape), `failclosed` (scoped error-to-bool ban exempting pure `errors.Is`/`AsType`, opaque & zero-value checks), `secrettaint` (`SecretBox` type ban + `Use` local direct-sink ban without false `len(plain)` taint), `osboundary` (`core/osfs` / `internal/host/sys` whitelists), `noimplicit` (no `init()`, mutable globals, `context.WithValue` outside `trace`, anonymous interface assertions, inline `//nolint:`, or bare `time.Duration` in JSON v2 DTOs), and `digestcover` (zero `reflect`).
- **Phased Execution**: Full 28-task WBS and 7 mandatory gates (**G0 → G1 → G2 → G2.5 Walking Skeleton → G3 ∥ G4 → G5**) are detailed in [v2-implementation-plan.md](./v2-implementation-plan.md).
