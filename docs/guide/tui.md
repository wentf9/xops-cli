# TUI 凭据体验

```bash
xops tui
```

新安装默认使用离线凭据库和 key-file。Enter 打开 SSH 会话，`m` 打开监控，`l` 进入日志选择。需要认证时，界面先交出终端，再显示主机指纹、密码或私钥口令提示；验证成功后按保存策略写入凭据引用。返回界面时保留筛选、勾选和当前节点，并刷新保存后的引用。

自动保存只处理 XOps 发起并验证成功的认证提示。监控和日志采集在后台运行时不会弹出认证或解锁提示，也不会自动写回凭据。

## 保存策略

默认继承配置中的 `credential.remember_prompted`，新安装为 `always`。`ask` 在认证成功后询问，拒绝保存仍可使用本次连接；`never` 不自动保存。可单次覆盖：

```bash
xops tui --remember never
```

这个选项同时禁止本次自动迁移，不修改全局配置。显式提交凭据表单和显式迁移属于独立的管理操作；原有密码不会回填到表单中。

保存失败会保留连接，恢复界面后仍会显示“未确认保存”的状态。若自动保存服务在启动时无法初始化，TUI 仍可连接，但会明确提示新输入的凭据无法保存；修复配置或凭据目录权限后重新启动 TUI。只读 doctor 检查通过不代表目录具备写权限。

## 终端与连接归属

连接、监控和日志入口都在界面释放终端后认证。SSH 会话在当前进程中运行，与表单共享同一配置仓库，不再依靠子进程等待回车。失败信息回到 TUI 状态栏。

每次用户发起的连接操作建立新的连接器，并关闭上一连接器，避免在 TUI 编辑目标后沿用旧会话。监控和日志可保留已认证连接；返回界面后关闭提示和自动写回权限。取消或退出会等待未完成的认证和输入操作停止。

`Ctrl+L` 锁定当前进程的离线库会话；`Ctrl+U` 在释放终端后解锁默认离线库。后台操作仍保持非交互策略。
