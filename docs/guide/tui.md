# 终端管理界面（TUI）

运行 `xops tui` 打开交互式终端管理界面，可在一个窗口内浏览筛选节点、发起 SSH 会话、查看实时监控、搜索远端日志以及新增或编辑节点。

```bash
xops tui
```

## 快捷键速查

| 按键 | 操作 |
| --- | --- |
| `Enter` | 连接当前选中节点的 SSH |
| `/` | 搜索 / 筛选节点列表 |
| `Space` | 勾选或取消勾选节点（用于批量打标签） |
| `n` / `e` | 新增节点 / 编辑当前节点 |
| `g` | 管理已勾选（或当前）节点的标签 |
| `m` / `l` | 打开节点监控面板 / 进入日志路径选择 |
| `Ctrl+S` / `Esc`（表单中） | 保存表单 / 取消并返回列表 |
| `Ctrl+U` / `Ctrl+L` | 解锁默认离线凭据库 / 锁定当前进程已打开的离线库 |
| `Ctrl+左/右方向键` | 在筛选框、表单、日志路径与搜索框中按词移动光标（含 Windows 控制台） |

退出 SSH 会话、监控或日志界面返回节点列表时，之前的筛选词、勾选项和光标位置都会保留。

## 常用操作

### 1. 新增与编辑节点

按 `n` 打开新增节点表单，按 `e` 编辑当前节点，`Ctrl+S` 保存，`Esc` 返回：
- **保存前验证（默认开启）**：提交新增节点时默认先验证 SSH 认证。验证通过直接保存；若验证失败，底部显示具体原因并询问 `[y/N]`——仅输入 `y` 才会保存，按回车、`n` 或 `Esc` 均不保存并回到表单修改（验证期间按 `Ctrl+C` 可取消）。
- **离线添加**：若目标主机暂不可达，可在表单的“保存前验证”栏选择 **“跳过验证直接保存”**（仅跳过网络连接检查，仍会校验配置与凭据存储；编辑已有节点不受此项影响）。
- **校验提示**：若别名已被其他节点占用或切换字段（`Tab`/方向键）触发校验错误，错误信息会固定显示在表单底部并自动换行、滚动定位当前输入行，已填写的表单内容不会丢失。

### 2. 管理标签

先用 `Space` 勾选一个或多个节点，再按 `g` 打开标签管理：
- **已有标签选择**：当配置中存在标签（含仅有 1 个标签）时，按 `Tab` 切到“选择已有标签”栏，用方向键移动、`Space` 勾选/取消，按 `Enter` 确认后进入新标签输入框（若尚无任何已有标签，则直接聚焦新标签输入框）。

### 3. 连接、监控与日志

- 进入 SSH（`Enter`）、监控（`m`）或日志（`l`）前，若需要认证或解锁，界面会先暂停 TUI 键盘读取并显示隐藏密码输入提示；返回后自动恢复。
- **后台无弹窗原则**：监控采集与日志流运行期间不会弹出密码或凭据库解锁提示，也不会自动写回凭据。若凭据失效或离线库未解锁，请先返回列表按 `Ctrl+U` 解锁或按 `e` 修正凭据后再打开。

## 凭据保存策略

TUI 默认沿用配置中的 `credential.remember_prompted`（新安装默认为 `always`，验证成功后自动存入离线凭据库与 `credentials.key`）。也可以在启动时临时覆盖单次会话策略，不修改全局配置：

```bash
xops tui --remember never
xops tui --remember ask
```

- **保存异常提示**：若 SSH 认证已通过但自动保存失败，本次连接仍可正常使用，返回 TUI 后状态栏会保留“未确认保存”提示；若启动时凭据保存服务无法初始化，TUI 仍允许连接，但会提示新输入的凭据无法保存（修复目录权限后重启 TUI 即可；注意 `credential doctor` 只读通过不代表目录可写）。
- **配置版本**：Schema v1 兼容期已结束，启动 TUI 前需先按[凭据迁移](./migration)升级旧配置。显式提交凭据表单属于独立管理操作，已有密码不会回填显示在表单中。

## 终端显示与自适应

- **备用屏幕与恢复**：TUI 使用终端备用屏幕（Alternate Screen），正常退出或按 `Ctrl+C` 中断时均会恢复原有终端内容与输入状态。
- **明暗主题自动切换**：启动时自动查询终端背景色，节点列表、日志列表和表单随之切换浅色或深色配色（终端未响应时默认使用深色配色；标签表单中已选标签保持绿色高亮，未选项自动适配对比度）。
- **窗口缩放与粘贴**：筛选框、表单、日志路径与搜索框均支持直接粘贴；调整终端窗口大小时（包括 Windows 终端），布局、错误提示省略号和当前焦点行会自动重排，且保存过程中缩放窗口不会影响正在提交的凭据内容。
