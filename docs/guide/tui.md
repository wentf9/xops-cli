# 终端管理界面（TUI）

```bash
xops tui
```

界面使用备用屏幕，退出后恢复原终端内容。节点筛选、表单、日志路径和日志搜索支持终端粘贴；调整窗口大小时界面会重新布局，Windows 终端也会自动更新，无需按键或重新进入界面。启动时会查询终端背景色，节点列表、日志列表和表单根据终端回复切换明暗配色；列表刷新后保留该配色。终端未回复背景色时，列表使用默认深色配色。标签表单的未选中选项随明暗背景调整前景色，已选标签保持绿色标识。

文本输入支持 Ctrl+左/右方向键按词移动光标，包括 Windows 控制台中的节点筛选、表单、日志路径和日志搜索。

进入 SSH 会话或凭据解锁提示前，界面会停止终端输入读取；返回后恢复读取。按 Ctrl+C 退出或取消操作时，会关闭输入读取并恢复终端状态。

新安装默认使用离线凭据库和 key-file。Enter 打开 SSH 会话，`m` 打开监控，`l` 进入日志选择。需要认证时，按提示核对主机指纹并输入密码或私钥口令；验证成功后按保存策略保存。返回界面时保留筛选、勾选和当前节点。

自动保存只处理 XOps 发起并验证成功的认证提示。监控和日志采集在后台运行时不会弹出认证或解锁提示，也不会自动写回凭据。

## 保存策略

默认继承配置中的 `credential.remember_prompted`，新安装为 `always`。`ask` 在认证成功后询问，拒绝保存仍可使用本次连接；`never` 不自动保存。可单次覆盖：

```bash
xops tui --remember never
```

这个选项同时禁止本次自动迁移，不修改全局配置。显式提交凭据表单和显式迁移属于独立的管理操作；原有密码不会回填到表单中。

保存失败会保留连接，恢复界面后仍会显示“未确认保存”的状态。若自动保存服务在启动时无法初始化，TUI 仍可连接，但会明确提示新输入的凭据无法保存；修复配置或凭据目录权限后重新启动 TUI。只读 doctor 检查通过不代表目录具备写权限。

## 常用操作

新增节点的表单默认选择“进行验证”。提交后先验证 SSH 身份认证，通过后保存；失败时显示原因并询问是否仍然保存，输入 `y` 确认保存，回车、`n` 或 Esc 默认不保存并返回表单供修改。验证期间按 Ctrl+C 退出会取消操作。

等待验证失败后的确认时，界面优先保留确认问题和 `[y/N]`，暂不显示编辑快捷键帮助；已完成的表单会让出空间显示失败原因。保存使用本次提交的内容，保存期间调整窗口不会改变待保存的凭据。

需要离线添加时，在“保存前验证”字段中显式选择“跳过验证直接保存”。此选项只跳过连接检查，不跳过配置和凭据存储检查；编辑已有节点的保存行为不受影响。

节点表单中按 `Ctrl+S` 保存，按 `Esc` 返回列表。别名被其他节点占用时，错误提示显示在表单底部并保持可见；已输入的内容保留，可修改后重新保存。底部提示根据窗口宽度换行，表单优先保留当前字段的输入空间。提示过长时显示省略标记，扩大终端窗口可查看完整内容。

按 Tab 或方向键切换字段时触发的校验错误也显示在同一提示区域。提示出现或窗口尺寸改变后，表单会重新定位当前字段，保持输入行可见，包括末尾的标签字段。

| 按键 | 操作 |
| --- | --- |
| `Enter` | 连接当前节点的 SSH |
| `/` | 筛选节点 |
| `Space` | 勾选或取消勾选节点 |
| `n` / `e` | 新增或编辑节点 |
| `g` | 管理标签 |
| `m` / `l` | 打开监控或日志选择 |
| `Ctrl+L` | 锁定当前进程已打开的离线库 |
| `Ctrl+U` | 解锁默认离线库 |

进入 SSH、监控或日志前，需要认证时会显示输入提示，密码输入不回显。连接失败的原因显示在状态栏。编辑连接目标后，下次连接使用更新后的配置。

后台监控和日志采集不会弹出密码提示。凭据不可用时，请返回列表，解锁凭据库或修正凭据后重新打开相应操作。
