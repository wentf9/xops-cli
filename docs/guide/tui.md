# 终端工作台（TUI）

XOps v2 内置基于 **Bubble Tea v2** 与 **Lipgloss v2** 构建的实时交互式终端工作台（`xops tui`），将资产浏览、实时主机指标流、远端实时日志流、操作/连接池投影与受监督的交互式 SSH 终端接管统一在一个纯事件驱动界面中。

## 1. 启动工作台

```bash
# 使用默认配置启动（启用交替屏幕缓冲区 AltScreen）
xops tui

# 指定初始聚焦节点、自定义指标刷新间隔或禁用交替屏幕
xops tui --node web-01 --refresh 2s
xops tui --no-alt-screen

# 搭配替代 OpenSSH 配置、严格安全档或显式初始界面语言
xops tui -F ~/.ssh/config.work --policy strict --lang zh
```

| 标志 | 说明 |
| --- | --- |
| `--node <id>` | 启动时初始聚焦的目标节点 ID |
| `--refresh <duration>` | 实时主机指标采样刷新间隔（如 `2s`、`5s`） |
| `--no-alt-screen` | 禁用终端交替屏幕缓冲区 |
| `-F <configfile>` | 替代 OpenSSH 配置文件路径（传 `none` 禁用） |
| `--policy <profile>` | 策略配置档：`direct_operator` \| `strict` \| `strict_agent` |
| `--lang <en\|zh>` | 指定启动时的初始界面语言（未指定时按环境优先级探测；进入后可按大写 `L` 随时热切） |

> `xops tui` 为交互式终端界面，显式拒绝 `--json` 选项。

## 2. 五大工作台视图

顶部状态栏实时展示 5 个视图标签以及全局事件计数（`events`、`dropped`、`streams`）：

1. **`1:Hosts`（资产节点视图）**：列出当前加载的全部托管主机/节点（ID、端点、用户名、来源 `origin` 与标签 `[tags]`）及当前配置修订号（`rev`），支持实时过滤与一键接管进入交互式 SSH。
2. **`2:Metrics`（实时主机指标视图）**：展示选中节点的实时 CPU 使用率、1/5/15 分钟负载、内存使用率、磁盘挂载使用率与 Top 进程列表，支持动态切换按 CPU 或内存排序。
3. **`3:Logs`（实时日志流视图）**：流式查看远端日志（默认 `/var/log/syslog`），支持滚动浏览与关键词过滤，超长行明确标记 `[truncated]`。
4. **`4:Operations`（操作、连接池与诊断投影视图）**：实时聚合单次操作状态（`RUNNING` / `OK` / `FAILED` / `UNKNOWN`）、连接池租约事件与系统诊断告警。
5. **`?:Help`（快捷键帮助视图）**：随时展示全部内置控制键位说明。

## 3. 完整快捷键参考

| 按键 | 作用 |
| --- | --- |
| `1` / `2` / `3` / `4` / `?` | 直接切换至 Hosts / Metrics / Logs / Operations / Help 视图 |
| `Tab` / `Shift+Tab` | 顺时针 / 逆时针循环切换视图 |
| `j` / `k` 或 `Down` / `Up` | 在 Hosts 视图移动选中光标，或在 Logs 视图上下滚动 |
| `g` / `Home` 与 `G` / `End` | 跳至列表顶部 / 底部 |
| `/` | 进入当前视图过滤模式（输入关键词即时筛选，`Enter` 确认，`Esc` 清空，`Backspace` 删除） |
| `r` | 从核心 Engine 刷新资产快照（原子快照查询，零撕裂读） |
| `m` | 切换至 Metrics 视图并对当前选中主机启动实时指标流 |
| `l`（小写） | 切换至 Logs 视图并对当前选中主机启动实时日志流（注意与大写 `L` 区分） |
| `x` | 停止当前所有活跃的指标流与日志流 |
| `s` | 在 Metrics 视图中切换 Top 进程排序方式（`CPU` / `Mem`） |
| `L`（大写） | **实时热切换界面语言**（英文 / 简体中文）：立即重绘全部 5 个视图、窗口标题、状态栏与安全横幅，且同步切换后续 `Enter` 交互接管提示语种 |
| `Enter`（Hosts 视图） | **受监督交互式终端接管**：排空 TUI 渲染 -> 释放终端给交互式 SSH 会话 -> 退出 SSH 后自动恢复 TUI 工作台 |
| `q` / `Ctrl+C` | 干净退出工作台并确定性恢复终端原始状态 |

### 实时语言切换（大写 `L`）行为说明

- **大小写严格区分**：大写 **`L`** 切换中英文界面；小写 **`l`** 保持启动远端实时日志流。
- **过滤输入模式不误触**：按 `/` 进入过滤编辑态时，输入大写 `L` 会作为搜索关键词追加到过滤框，绝不误触发语种切换；按 `Enter` 或 `Esc` 退出过滤编辑态后恢复快捷键功能。
- **接管交互提示同步切换**：按 `L` 切换语种时会即时同步底层交互适配器（`OnLocaleChange`），随后在主机视图按 `Enter` 接管进入交互式 SSH 会话时，主机密钥指纹确认与口令提示会自动使用切换后的语种，且退出 SSH 返回工作台后继续保留该语种。
- **会话级生效、零落盘**：热切换仅在当前 TUI 进程生命周期内生效，不改写 `~/.xops/config.yaml`。

## 4. 实时安全熔断与不确定态横幅

工作台顶部内置两类高优先级实时安全告警横幅：

- **红色熔断横幅（`SECURITY GATE HALTED`）**：当引擎在 `strict_agent` 等模式下因审计写失败触发不可逆熔断时立即醒目提示并展示熔断原因，提醒操作员立即排查本地审计日志与磁盘状态。
- **琥珀色警告横幅（`WARNING: OutcomeUnknown detected — DO NOT auto-retry`）**：当任意操作流中观测到 `OutcomeUnknown` 终态时常驻提示，防止误判与盲目重试。
