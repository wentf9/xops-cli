# SFTP 与文件传输

XOps 提供交互式 SFTP 终端（`xops sftp`）和命令行文件分发工具（`xops scp`）。

## 快速上手

### 1. 使用 SCP 上传、下载与批量分发

```bash
# 上传单个文件或目录到远端用户家目录
xops scp ./test.tar 'web-01:~/tmp/' -v

# 从远端下载到本地
xops scp 'web-01:~/tmp/test.tar' ../ -v

# 按标签批量分发文件到多台服务器（注意为包含 ~ 的远端路径加引号，防止被本地 Shell 展开）
xops scp ./config.conf --tag web --dest '~/tmp/'
xops scp ./config.conf --tag web --dest /etc/app/
```

- **路径规则**：远端路径支持 `~` 和 `~/...`，以远端 SFTP 登录目录（通常为该用户家目录）为基准，适用于上传、下载、远端中转和批量上传。不支持 `~其他用户`，请改用绝对路径。
- **覆盖策略**：交互确认回答 `y` 或传入 `--force` 会覆盖已有文件（即使大小和修改时间相同）；`--no-clobber` 会跳过已有目标。确认目标目录权限，避免误覆盖重要文件。
- **本地下载替换**：本地下载优先使用原子重命名替换。若文件系统拒绝重命名覆盖已有普通文件，则先备份原文件再放入下载文件，失败时自动恢复原文件（该回退流程非原子操作；若恢复失败，错误会给出原文件备份路径）。同名目录不会被当作普通文件替换。

### 2. 使用交互式 SFTP Shell

```bash
xops sftp web-01
```

进入 SFTP 提示符后可输入 `help` 查看全部命令。常用操作：

```text
pwd
ls
cd /var/tmp
put ./report.txt
get report.txt
exec date
exit
```

- `exec <命令>`：在当前远端目录执行命令（交互模式下分配 PTY 以支持终端程序），结束后返回 SFTP 提示符。
- `shell` / `lshell`：进入远端或本地交互式 Shell；`lexec`：执行本地命令。退出子程序后恢复 SFTP 提示符。
- 连接中断时 SFTP Shell 会立即退出并返回非零状态，不会继续接受无效操作。

## 交互输入与快捷键

SFTP 提示符支持行编辑、命令历史（默认保存在 `~/.xops_sftp_history`）以及本地/远端路径补全：

| 按键 | 行为 |
| --- | --- |
| `Tab` / `Shift+Tab` | 请求路径补全，并在多个候选中正向/反向循环切换（跨页自动翻页） |
| `PageUp` / `PageDown` | 在补全候选面板中整页翻动（首尾页不循环） |
| `Enter` / `Esc`（补全中） | `Enter` 确认候选并返回编辑（不直接执行命令）；`Esc` 关闭候选面板 |
| `↑` / `↓`、`Ctrl+P` / `N` | 浏览历史记录；回到最新位置时恢复当前输入草稿 |
| `Ctrl+R` | 反向搜索历史；再次按下查找更早的匹配 |
| `Enter` / `Esc` / `Ctrl+G`（搜索中） | `Enter`/`Esc` 接受匹配并返回编辑；`Ctrl+G` 取消搜索并恢复草稿 |
| `Home` / `End`、`Ctrl+A` / `E` | 移动到行首 / 行尾 |
| `Ctrl+U` / `K` / `W` | 删除光标前内容 / 光标后内容 / 前一个单词 |
| `Delete` / `Ctrl+D` | `Delete` 删除光标后字符；`Ctrl+D` 在空行退出，非空行删除光标后字符 |
| `Ctrl+C` | 取消当前输入；在覆盖/删除确认提示中停止本条命令的剩余文件处理（回答 `n` 仅跳过当前文件） |

**编辑器与历史细节**：
- **补全面板**：唯一候选直接上屏；补全目录后可继续按 `Tab` 补全子项。多候选面板按终端宽度分列，最多显示 6 行并附带页码与总数，选中项带 `>` 标记。后台补全最长等待 2 秒，继续打字或退出提示符会自动取消过期查询。
- **长行与粘贴**：长命令水平滚动，提交后完整回显到终端滚动区；支持中文、组合字符、emoji 和跨提示符的括号粘贴（粘贴中的换行与制表符转为空格，不会自动执行命令）。即使 `stdout` 被管道传给 `tee`，只要 `stdin` 是终端，提示符和尺寸自适应依然正常工作。
- **历史容错**：最多保留最近 500 条非空且非连续重复的交互命令（确认回答与批处理命令不记录）。若启动时历史文件或锁不可用，会告警并降级为内存历史；写入失败（Windows 短暂文件占用会在 2 秒内重试）不会清空旧历史，恢复后自动合并写回。

## 批处理模式

当标准输入来自管道或文件重定向（如 `xops sftp web-01 < batch.txt`）时，自动进入批处理模式：
- 任一命令失败立即停止并返回非零退出码，不再执行后续命令，也不写交互历史。
- 批处理中的 `lls`/`lll` 和远端 `ls`/`ll` 遇到路径不存在或目录读取失败会立即失败；通配符匹配中任一路径列出失败也会停止剩余匹配和后续命令。
- 批处理 `exec` 不申请 PTY，`exec` 和 `lexec` 的标准输入直接为 `EOF`（不会吞掉后续 SFTP 命令）。
- `shell`/`lshell` 需要交互终端，不能在批处理中使用；涉及覆盖或删除确认的操作必须显式配合 force/no-clobber 选项，否则直接报错。单行命令长度上限为 1 MiB。

## `exec` 工作目录继承与自动探测

在 SFTP 中通过 `cd` 切换远端目录后，`exec` 会将当前目录与用户命令一并交给远端解释器执行：

- **POSIX 与 fish（`bash`/`sh`/`zsh`/`fish`）**：非空工作目录使用条件代码块（`cd ... && { ...; }` 或 fish 的 `cd ...; and begin ... end`）保护整个用户命令。目录切换失败时，分号分隔或多行命令均不会执行；切换成功后保留用户程序的退出码。
- **Windows CMD（`cmd` 及已保存的 `server/cmd`）**：使用 `cd /d "目录" || exit /b & 用户命令`。切换失败时立即退出并保留失败状态，后续 `&`、`&&`、`||` 或分组命令均不会执行；切换成功后保留原生 CMD 语法、注释和退出码。已保存为 `server/cmd` 的节点在带 `cwd` 执行 `exec` 时会临时派生 CMD 适配器，无需重探且不修改节点配置。
- **Windows 路径转换**：Windows SFTP 下的 `/C:/...` 会转换为 `C:/...`，根目录 `/C:` 与 `/C:/` 均转换为 `C:/`（在 `sftp:/C:>` 下执行 `exec dir` 即可列出 C 盘根目录）。跨平台 `pwsh` 根据自身 `$IsWindows` 自动选择路径格式，POSIX 路径保持不变。
- **按需自动探测**：当节点未指定执行配置且启动方言未知时，非空目录的 `exec` 会在执行前自动进行一次有界只读探测，并在当前连接内缓存结果（Linux 优先选用默认 `bash`/`sh`/`zsh`/`fish`，Windows CMD 环境若装有 PowerShell 则优先选用受控 PowerShell 适配器，仅 CMD 时使用 CMD）。空目录的普通命令不触发探测；除 `server/cmd` 外的显式 `server` 配置拒绝非空工作目录；探针失败会在用户命令开始前报错，绝不换解释器重试用户命令。
