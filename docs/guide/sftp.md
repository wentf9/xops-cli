# SFTP 与文件传输

批处理中的 `lls`/`lll` 和远端 `ls`/`ll` 遇到路径不存在或目录读取失败时也会立即失败；通配符匹配结果中任一路径列出失败，会停止剩余匹配及后续命令。

管道或文件输入自动进入批处理模式：任一命令失败立即停止并返回非零状态，不执行后续命令，不写交互历史。批处理 `exec` 不申请 PTY；`exec` 和 `lexec` 的标准输入为 EOF，不会读取后续 SFTP 命令。`shell/lshell` 需要交互终端；覆盖或删除需要确认时，必须使用已有的 force/no-clobber 选项，否则报错。单行命令上限为 1 MiB。交互终端中普通命令失败会显示错误并允许继续，连接或输出故障仍会终止会话。

```bash
xops sftp web-01
```

进入 SFTP shell 后用 `help` 查看完整命令。常用操作：

```text
pwd
ls
cd /var/tmp
put ./report.txt
get report.txt
exec date
exit
```

`exec` 在当前远端目录执行命令，并提供 PTY 以支持终端程序。命令结束后返回 SFTP 提示符。`shell` 进入远端 shell，`lexec` 执行本地命令；退出远端交互程序后才继续输入 SFTP 命令。

批量文件分发使用 SCP：

```bash
xops scp ./config.conf --tag web --dest /etc/app/
```

确认目标目录权限，避免覆盖不应修改的文件。连接中断时 SFTP shell 会退出并返回失败状态，不会继续接受无效操作。

## 交互输入与快捷键

SFTP 提示符支持行编辑、命令历史以及本地和远端路径补全。长命令在输入区域内水平滚动，光标按可见区域的实际显示列定位，支持中文、组合字符和 emoji。终端尺寸改变时会调整显示宽度。连续输入的多条命令会在后续提示符中依序读取，不会因前一条命令提交而丢弃。

| 按键 | 行为 |
| --- | --- |
| Delete | 删除光标后的字符；空行和行尾不执行任何操作 |
| Ctrl+D | 空行退出；非空行删除光标后的字符 |
| Ctrl+C | 取消当前输入；确认提示中停止本条命令的剩余文件处理 |
| Home/End、Ctrl+A/E | 移动到行首／行尾 |
| Ctrl+U/K/W | 删除光标前内容／光标后内容／前一个单词 |
| ↑/↓、Ctrl+P/N | 浏览历史；返回最新位置时恢复输入草稿 |
| Ctrl+R | 反向搜索历史；重复按下搜索更早的匹配 |
| Enter / Esc（历史搜索中） | 接受搜索结果并返回编辑，不立即执行 |
| Ctrl+G（历史搜索中） | 取消搜索并恢复草稿 |
| Tab / Shift+Tab | 请求补全，然后正向／反向切换候选，跨页时自动翻页 |
| PageUp / PageDown（候选面板中） | 整页翻动，尽量保留页内选中位置；首尾页不循环 |
| Enter（补全候选显示时） | 确认当前候选并返回编辑，不执行命令；尚未选择时采用第一项 |
| Esc | 关闭补全候选 |

唯一候选会直接插入；补全到目录后，可继续按 Tab 补全目录内的内容，无需先输入字符。多个候选时，Tab / Shift+Tab 循环选择当前候选，选中项在列表中反色高亮并带有 `>` 标记；候选面板按终端宽度排列多列，最多显示六行候选，底部显示页码和候选总数；终端较矮时会减少行数。窗口缩放后仍保持选中项可见。禁用颜色时仍保留 `>` 标记。Enter 确认并关闭候选列表。确认目录后可继续按 Tab 补全子项；退出候选选择后，再按 Enter 才执行命令。继续输入更具体的前缀后再按 Tab，可以缩小候选范围。候选较多时只渲染当前页。

粘贴文本中的换行和制表符转换为空格，控制字符被移除；粘贴本身不会执行命令，需按 Enter 提交。路径补全在后台查询，最长等待两秒；编辑输入或退出提示符会取消查询，过期结果不会覆盖新输入。取消或超时后可直接再次请求远端补全，无需先执行其他命令。历史搜索中粘贴文本会追加搜索词，不会修改正在显示的历史命令。

历史文件或锁文件在启动时不可用，会显示告警并降级为会话内历史，不影响 SFTP shell 启动；可读取的旧历史仍可浏览，此降级模式不会写入磁盘。正常情况下，命令历史保存到 `~/.xops_sftp_history`，最多保留最近 500 条，忽略空输入和连续重复命令。确认答案和批处理命令不写入历史；确认提示中不启用命令补全或历史浏览。历史写入失败会显示错误，会话内仍保留该命令；后续写入恢复时，会将待保存记录与磁盘历史合并写入，仍保留最近 500 条。

执行命令和进入本地／远端交互程序前，提示符停止读取并恢复终端。程序退出后重新显示 SFTP 提示符；连接断开或取消会结束等待中的输入和补全任务。

覆盖或删除确认中，回答 `n` 仅跳过当前项；Ctrl+C 则停止本条命令的剩余处理并返回提示符。已完成的文件操作不会撤销。
